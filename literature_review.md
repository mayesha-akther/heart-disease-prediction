# Literature Review

## Topic: Heart Disease Prediction Using Machine Learning

### Source 1: UCI Machine Learning Repository – Heart Disease Dataset

The UCI Heart Disease dataset is a classification dataset containing 303 patient records and 13 features. The dataset includes clinical variables such as age, sex, chest pain type, resting blood pressure, cholesterol, maximum heart rate, exercise-induced angina, ST depression, and other cardiovascular measurements. The target variable represents the presence or absence of heart disease.

Source:
https://archive.ics.uci.edu/dataset/45/heart+disease

### Source 2: Nasution et al. (2025)

Nasution et al. investigated heart disease prediction using several machine learning algorithms, including Logistic Regression, Random Forest, Support Vector Machine, and K-Nearest Neighbors. The study evaluated the models using accuracy, precision, recall, and F1-score and demonstrated that traditional machine learning models can be applied to the UCI heart disease dataset for classification.

Source:
https://doi.org/10.25299/itjrd.2025.17941

### Source 3: Scientific Reports (2020)

This study investigated machine learning approaches for early heart disease diagnosis using datasets from the UCI Machine Learning Repository. Several classification algorithms, including Logistic Regression, Decision Tree, Naive Bayes, Random Forest, and Artificial Neural Network, were examined. The study also explored feature-selection methods to identify important variables for heart disease prediction.

Source:
https://www.nature.com/articles/s41598-020-76635-9

## Summary

The reviewed sources show that machine learning can be applied to structured clinical data for heart disease classification. Different algorithms can produce different results, so comparing more than one model is useful for evaluating model performance. Based on these findings, this project will compare Logistic Regression and Random Forest using the UCI Heart Disease dataset.
